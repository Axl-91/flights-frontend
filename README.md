# Flights Frontend

Frontend application for [flights-api-ts](https://github.com/Axl-91/flights-api-ts), a flight management API.

This application provides a visual dashboard to explore flight information, passengers, and their assigned seats after the check-in simulation.

## Features

- **Flight selection:** Browse between the four available flights.
- **Flight information:** View departure and arrival airports.
- **Seat map:** Visualize the airplane layout, including occupied and available seats.
- **Passenger details:** Select a seat to inspect the assigned passenger's information.
- **Purchase groups:** Identify passengers who belong to the same purchase.

## Requirements

- Node.js
- npm

## Getting Started

Clone the repository and install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.
